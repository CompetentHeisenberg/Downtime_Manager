# Нефункціональні вимоги

## 1. Продуктивність

Система повинна відображати основні сторінки та результати запитів не більше ніж за 5 секунд за нормального навантаження.

## 2. Надійність

Система повинна зберігати зареєстровані дані про простої та не допускати їх втрати після перезавантаження системи.

## 3. Безпека

Система повинна забезпечувати автентифікацію користувачів та обмежувати доступ до функцій відповідно до їх ролі.

## 4. Зручність використання

Інтерфейс системи повинен бути зрозумілим користувачам та дозволяти виконувати основні операції без спеціальної технічної підготовки.

## 5. Масштабованість

Система повинна підтримувати збільшення кількості записів про простої без суттєвого зниження продуктивності.
